Cómo redactar una carta de presentación eficaz

  1. Nombrar el puesto. El asunto y la primera frase deben indicar exactamente qué puesto desea: los reclutadores clasifican las candidaturas por ello.
  2. Responder a la oferta. El párrafo central no es la historia de su vida: son 2-3 requisitos del anuncio de empleo, cada uno respondido con un resultado real y medible.
  3. Mantener it to one page. Tres párrafos cortos superan siempre a una carta larga. Termine pidiendo la entrevista.

Preguntas frecuentes

Is this carta de presentación builder really free, including the PDF?

Yes. Like the resume builder, there is no server and no checkout: the letter is built en el navegador and the PDF is created by el navegador's print function. Free means free.

¿Dónde se guarda la carta mientras se trabaja?

Only en el navegador's local storage on this device (key: loona_cover_letter_v1). Nothing is uploaded. Press Clear Everything to delete it permanently.

Should my carta de presentación match my resume?

Yes - use the same name, title and datos de contacto, and the same professional tone. This builder uses the Classic letter layout that sits naturally beside the Classic resume template.

What if I do not know the responsable de contratación's name?

Dejar el campo en blanco y la carta empezará con «Estimado responsable de contratación,», algo totalmente aceptable. Nunca inventar un nombre.
