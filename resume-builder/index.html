Frequently Asked Questions

How do I save my resume as a PDF?

Press the Print / Save as PDF button. In the print dialog, choose "Save as PDF" (or "Microsoft Print to PDF") as the destination, set margins to None and turn on "Background graphics" so the template colours print exactly as previewed. The file is created by your browser - free, with no watermark.

Where is my resume saved while I work?

Only in your browser's local storage, on your own device. Nothing is uploaded. Come back on the same device and browser and your draft is still here. Press Clear Everything to delete it permanently.

My resume is longer than one page - is that OK?

For most people one page is best. If your experience genuinely needs two pages, the builder will flow onto a second A4 page when you print. Cut older, less relevant roles first - recruiters reward focus.

Does the Modern template's side panel break ATS software?

No. The panel is real text laid out in reading order (summary, experience, education, then contact, skills and languages), not an image or a table, so applicant-tracking software reads it in sequence. If you want maximum simplicity, the Classic template is a single straight column.

Which template is best for ATS software?

The ATS template: a plain single column with standard headings and no tables, columns or graphics, so applicant-tracking software reads it cleanly. The Compact template is best when you need to fit a long career on one page, and the Executive template suits senior roles.
