Perguntas Frequentes

Como guardo o meu currículo como PDF?

Prima o botão Imprimir / Guardar como PDF. Na caixa de diálogo de impressão, escolha "Save as PDF" (ou "Microsoft Print to PDF") como destino, defina as margens para None e ative "Background graphics" para que as cores do modelo imprimam exatamente como pré-visualizadas. O ficheiro é criado pelo seu navegador - grátis, sem marca de água.

Onde é guardado o meu currículo enquanto trabalho?

Apenas no armazenamento local do seu navegador, no seu próprio dispositivo. Nada é carregado. Volte no mesmo dispositivo e navegador e o seu rascunho continua aqui. Prima Limpar Tudo para o apagar permanentemente.

O meu currículo tem mais de uma página - está bem?

Para a maioria das pessoas, uma página é o melhor. Se a sua experiência precisa genuinamente de duas páginas, o criador passará para uma segunda página A4 quando imprimir. Corte primeiro as funções mais antigas e menos relevantes - os recrutadores recompensam o foco.

O painel lateral do modelo Modern quebra o software ATS?

Não. O painel é texto real disposto por ordem de leitura (resumo, experiência, educação, depois contacto, competências e línguas), não uma imagem ou uma tabela, por isso o software de gestão de candidaturas lê-o em sequência. Se quer a máxima simplicidade, o modelo Classic é uma única coluna direta.

Que modelo é o melhor para software ATS?

O modelo ATS: uma única coluna simples, com títulos padrão e sem tabelas, colunas ou gráficos, para que o software de gestão de candidaturas o leia de forma limpa. O modelo Compact é o melhor quando precisa de colocar uma carreira longa numa página, e o modelo Executive adequa-se a funções seniores.
